# test_data/

Inputs for tests and for the dev utilities: fixtures, sample documents, recorded cases,
config files a harness reads. Tracked, because a test whose input is not in the repo is
a test that only passes on one machine.

Output from those runs does NOT go here. It goes to `.output/` (byproducts, gitignored)
or `.test_output/` (per-run artefacts, gitignored).
